## What this workspace is

The pleme-io macro farm's typed engine. 16 crates that compose into:

1. **Spec types** (`PerFieldDeriveSpec`, `PerVariantDeriveSpec`,
   `NewtypeDeriveSpec`, `EnumFoldDeriveSpec`, `ProcDeriveSpec`,
   `CompositeDeriveSpec`, `ProcAttrSpec`, `ProcFnSpec`,
   `MacroRulesSpec`).
2. **Emitters** that turn a Spec into a complete proc-macro crate
   via `quote!{}` + `syn::parse2` + `prettyplease::unparse`.
3. **Catalog** (`MacroCatalogSpec`) that bundles N entries with
   per-entry metadata (description, since, owner, verifier_hint).
4. **Operator CLI** (`tatara-rust-forge`) with 6 subcommands —
   `emit-spec`, `catalog-emit-repos`, `catalog-emit-verify`,
   `catalog-gate-all`, `catalog-publish-all`, `catalog-instantiate`.
5. **Verification primitives** (`snapshot_spec!`,
   `assert_tokens_contain!`, `assert_tokens_eq!`) per the
   ★★ TOKEN-STABILITY directive.

## House rules — non-negotiable

- **★★ TYPED EMISSION** — every emitter produces source through
  `quote!{}` → `syn::parse2` → `prettyplease`. Raw `format!("...")`
  of code is banned. Pre-parse user-supplied template strings as
  `proc_macro2::TokenStream`, then interpolate the whole variable
  via `#var` in the outer `quote!{}` — splice trick is documented
  in `per_field.rs`.

- **★★ TOKEN-STABILITY** — emitter tests assert on tokens, never
  raw characters. Use `snapshot_spec!` for full-file, or
  `assert_tokens_contain!` / `assert_tokens_eq!` for fragments.
  Both ignore prettyplease's whitespace choices. Whitespace-stripping
  bandaids are banned; that's the smell that *triggered* the
  directive.

- **`SpecKind` is the single dispatch surface** — every new Spec
  type implements `tatara_rust_catalog::SpecKind` (which extends
  `CompileToCrate + Validate`). `CatalogSpec`'s `kind_label`,
  `validate`, `compile_to_crate`, `trait_name_for_verifier`
  methods are 1-line delegates through `as_spec_kind() -> &dyn SpecKind`.

- **Drift detectors are non-negotiable** — every catalog
  variant must have a row in `tests/repo_emission_matrix.rs`;
  every variant must have a `SpecKind` impl
  (`tests/spec_kind_contract.rs::variant_count_matches_expected_total`).
  Adding a new kind without these trips the test.

## Adding a new emitter primitive

Mirror the structure of `per_field.rs`:

1. **Define the Spec struct** with serde derives + sensible defaults
   (`#[serde(default, skip_serializing_if = ...)]` on optionals).
2. **`impl CompileToCrate`** — call
   `tatara_rust_ast::render_proc_macro_cargo_toml(name, description)`
   for the Cargo.toml; render the lib.rs via the typescape pattern.
3. **`impl Validate` in `tatara-rust-validate`** — call
   `check_ident` + `check_template_splices` for each template field.
4. **`impl SpecKind` in `tatara-rust-catalog`** — `kind_label()`
   returns the kebab-case JSON tag; `trait_name_for_verifier()`
   returns the user-facing trait/macro identifier.
5. **Add `CatalogSpec::<NewKind>` variant** + a 1-line arm in
   `as_spec_kind()`.
6. **Add `VerifierHint::<NewKindStrategy>`** + a `render_<X>_smoke`
   function in `tatara-rust-verify`. The smoke renderer's sample
   struct/enum must satisfy the new derive's contract (e.g. the
   InvalidatingSetter smoke includes a `last_seqno: u64` field).
7. **Add a matrix row** in `tests/repo_emission_matrix.rs` +
   bump the variant count assertion.

Run `cargo test --workspace`. Drift detectors will tell you if
you missed a site.

## Typescape pattern for `render_lib_rs`

The structural template every emitter follows:

```rust
fn render_lib_rs(spec: &<NewKind>DeriveSpec) -> String {
    use proc_macro2::TokenStream;
    use quote::{format_ident, quote};

    let trait_id = format_ident!("{}", spec.trait_name.0);
    let fn_name = format_ident!("{}", spec.fn_name());

    // Parse user-supplied template fragment as TokenStream.
    let body: TokenStream = spec.template_field
        .parse()
        .expect("template must parse as TokenStream");

    // Pre-parse `#name`-style literals to inject literal `#` tokens
    // into the emitted quote!{} (which itself runs at consumer compile).
    let hash_self_name: TokenStream = "#self_name".parse().unwrap();

    let file: TokenStream = quote! {
        #![doc = "GENERATED by tatara-rust-derive::<NewKind>DeriveSpec."]

        use proc_macro::TokenStream;
        use quote::quote;
        use syn::{Data, ..., parse_macro_input};

        #[proc_macro_derive(#trait_id)]
        pub fn #fn_name(input: TokenStream) -> TokenStream {
            let input = parse_macro_input!(input as DeriveInput);
            let self_name = &input.ident;

            // ... extract from input.data per the Spec's shape ...

            let expanded = quote! {
                impl #hash_self_name {
                    #body
                }
            };
            TokenStream::from(expanded)
        }
    };

    let parsed: syn::File =
        syn::parse2(file).expect("emitted lib.rs must parse as syn::File");
    prettyplease::unparse(&parsed)
}
```

The `hash_*` token-stream variables are the key trick: writing
`#self_name` directly inside `quote!{}` tries to bind an
emit-time variable; pre-parsing the literal into a TokenStream
variable and interpolating the WHOLE variable splices the `#`
tokens verbatim.

## How operators consume

`tatara-rust-forge catalog-instantiate <json> --out <dir> --publish --org pleme-io --skip-clippy`

That's it. Authors write the catalog; the substrate handles emit
+ verify + gate + publish.
